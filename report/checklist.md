# 지하철 출구별 혼잡도 예측 – 통합 현장 조사 가이드

> 조사 대상은 출구 계단·에스컬레이터 입구와 환승 통로이다. 개찰구 통과 인원은 교통카드 데이터로 집계되므로 조사하지 않는다 (PRD 1.3).

- 조사 일자: ____년 __월 __일 (요일: ___)

> 왜 필요? 시간대별 데이터를 구분해야 조명·밀집도 조건별로 전처리 파라미터를 따로 설정할 수 있다.

## 1. 카메라 설치 조건
### 1-1. 설치 높이
- [ ] 2m 미만  - [ ] 2~3m  - [ ] 3~4m  - [ ] 4m 이상
> 왜 필요? 높이에 따라 사람 크기가 달라지므로 검출 박스의 최소·최대 크기 필터 기준이 된다. 출구는 여러 명이 나란히 걸어 겹침이 많으므로 높을수록 유리하다.

### 1-2. 촬영 각도
- [ ] 수직 위에서 아래(탑뷰)  - [ ] 비스듬히(30~60도)  - [ ] 거의 정면
> 왜 필요? 각도에 따라 원근 보정(perspective transform) 적용 여부와 사람끼리 가림 정도가 결정된다.

### 1-3. 화면에 보이는 통과 구간
- [ ] 계단 1개  - [ ] 계단 + 에스컬레이터  - [ ] 평지 통로  - [ ] 기타: ________
> 왜 필요? 계단과 에스컬레이터를 따로 셀지, 통과선을 몇 개로 나눌지 정하는 기준이 된다.

### 1-4. 화면에 통과 구간 외 영역(벽, 상점, 다른 통로 등)이 차지하는 비율
- [ ] 거의 없음  - [ ] 절반 이하  - [ ] 절반 이상
> 왜 필요? 불필요한 영역을 마스킹해야 오검출과 연산량을 줄일 수 있다.

### 1-5. 카메라 흔들림
- [ ] 없음  - [ ] 열차 진입 시 약간  - [ ] 자주 흔들림
> 왜 필요? 흔들림이 있으면 영상 안정화(stabilization)를 넣거나 통과선 위치에 여유를 둬야 한다.

## 2. 조명 환경
### 2-1. 주 광원
- [ ] 형광등  - [ ] LED  - [ ] 자연광 혼합  - [ ] 혼합(구역마다 다름)
> 왜 필요? 형광등은 깜빡임(flicker)이 생길 수 있어 프레임 간 밝기 보정 필터가 필요하다.

### 2-2. 밝기 수준 (눈으로 판단)
- [ ] 밝음  - [ ] 보통  - [ ] 어두움  - [ ] 구역별 차이 큼
> 왜 필요? 어둡거나 밝기 차가 크면 히스토그램 평활화(CLAHE) 같은 명암 보정 강도를 정해야 한다.

### 2-3. 역광 (지상 출구·창문에서 빛이 들어옴)
- [ ] 없음  - [ ] 특정 시간대만  - [ ] 항상 있음
> 왜 필요? 역광이 있으면 사람이 검은 실루엣으로 찍혀 노출 보정이나 해당 영역 별도 처리가 필요하다. 계단 아래에서 지상 출구 쪽을 보는 카메라는 낮 시간에 거의 항상 역광이다.

### 2-4. 그림자
- [ ] 거의 없음  - [ ] 옅게 생김  - [ ] 진하고 길게 생김
> 왜 필요? 진한 그림자는 사람으로 오인될 수 있어 그림자 제거 또는 검출 신뢰도 임계값을 높여야 한다.

## 3. 배경 및 간섭 요소
### 3-1. 바닥 재질
- [ ] 무광(반사 없음)  - [ ] 약간 반사  - [ ] 심한 반사(대리석·광택)
> 왜 필요? 바닥에 비친 사람이 중복 검출될 수 있어 반사 영역 마스킹이 필요하다.

### 3-2. 화면 안의 유리·거울·스테인리스 면
- [ ] 없음  - [ ] 있음 (위치: ________)
> 왜 필요? 반사된 사람 형상을 제외하도록 해당 위치를 마스크로 지정해야 한다.

### 3-3. 화면 안의 디지털 광고판·모니터
- [ ] 없음  - [ ] 있음(정지 화면)  - [ ] 있음(영상 재생)
> 왜 필요? 광고 속 사람 이미지나 움직임이 오검출을 일으키므로 고정 마스크 처리 대상이다.

### 3-4. 화면 안에서 계속 움직이는 배경
- [ ] 없음  - [ ] 에스컬레이터  - [ ] 문(자동문)  - [ ] 기타: ________
> 왜 필요? 배경 움직임은 추적 오류의 원인이므로 해당 영역을 제외하거나 움직임 필터를 적용해야 한다.

## 4. 출구·통로 구조
### 4-1. 카메라 위치 유형
- [ ] 계단 하단(지하 대합실 쪽)  - [ ] 계단 상단(지상 출구 쪽)  - [ ] 에스컬레이터 입구  - [ ] 환승 통로
> 왜 필요? 위치마다 사람이 걷는 속도와 멈추는 지점이 달라 통과선 위치와 추적 파라미터가 달라진다. 지상 쪽은 날씨와 햇빛 영향을 직접 받는다.

### 4-2. 통과 방향
- [ ] 양방향 섞임  - [ ] 양방향이지만 좌우로 나뉨  - [ ] 시간대별로 한쪽이 대부분  - [ ] 한 방향 전용(에스컬레이터 등)
> 왜 필요? 방향 판별이 얼마나 어려운지, 들어오는 인원과 나가는 인원을 따로 셀 수 있는지 결정하는 기준이 된다.

### 4-3. 통로 폭과 통과선 앞 평지
- 통로(계단) 폭: ____m   - 계단·에스컬레이터 앞 평지 길이: ____m
- 여유: - [ ] 넓음  - [ ] 보통  - [ ] 좁음(바로 계단·벽)
> 왜 필요? 폭은 혼잡도 기준(폭 1m당 분당 인원)과 물리 한계 계산에 쓴다. 통과선은 계단 위가 아니라 앞 평지에 두므로 평지가 1.5m 이상인지 확인한다. 좁으면 사람이 겹쳐 가림 대응 설정을 강화해야 한다.

### 4-4. 같은 출구로 이어지는 다른 동선
- [ ] 없음  - [ ] 있음 (예: 반대편 계단, 엘리베이터, 건물 연결 통로: ________)
> 왜 필요? 카메라가 보지 않는 동선이 있으면 출구 인원이 적게 잡힌다. 카메라를 추가할지, 교통카드 대조에서 차이로 감안할지 정한다.

## 5. 승객 흐름 패턴
### 5-1. 체감 혼잡도
- [ ] 여유  - [ ] 보통  - [ ] 혼잡  - [ ] 매우 혼잡
> 왜 필요? 밀집도에 따라 겹친 박스를 제거하는 NMS 임계값과 추적 매칭 기준을 조정해야 한다.

### 5-2. 통과 모양
- [ ] 한 명씩 일렬  - [ ] 2~3명씩 나란히  - [ ] 덩어리로 몰림 (열차 도착 직후 등)
> 왜 필요? 붙어서 지나가면 한 명으로 합쳐 세질 수 있어 분리 검출 기준을 정하는 근거가 된다.

### 5-3. 통과 구간에서 멈추는 사람 (계단 앞 정체, 안내판 보기, 우산 펴기 등)
- [ ] 거의 없음  - [ ] 가끔  - [ ] 자주
> 왜 필요? 멈췄다 다시 움직이는 사람을 중복으로 세지 않도록 추적 유지 시간과 재카운트 금지 시간을 정해야 한다.

### 5-4. 비정상 이동 (역방향, 되돌아감, 통과선 근처에서 서성임)
- [ ] 거의 없음  - [ ] 가끔  - [ ] 자주
> 왜 필요? 선을 넘었다 돌아가는 경우를 걸러내는 방향·궤적 필터의 필요성을 판단한다.

## 6. 특수 객체
### 6-1. 자주 보이는 동반 물체 (복수 선택)
- [ ] 캐리어  - [ ] 유모차  - [ ] 휠체어  - [ ] 큰 배낭·짐  - [ ] 자전거  - [ ] 거의 없음
> 왜 필요? 물체가 사람으로 세지거나 사람을 가리지 않도록 클래스 필터와 박스 크기 기준을 조정해야 한다.

### 6-2. 어린이 동반 비율
- [ ] 거의 없음  - [ ] 가끔  - [ ] 많음(관광지·학교 근처)
> 왜 필요? 어린이는 박스가 작아 최소 크기 필터에 걸려 누락될 수 있다.

### 6-3. 복장 특징 (복수 선택)
- [ ] 두꺼운 외투  - [ ] 모자·후드  - [ ] 우산 소지  - [ ] 특이사항 없음
> 왜 필요? 머리가 가려지거나 실루엣이 커지면 탑뷰 머리 검출 정확도가 떨어져 보정 기준이 필요하다. 우산을 펴는 위치(보통 지상 출구 직전)는 따로 적어 둔다.
