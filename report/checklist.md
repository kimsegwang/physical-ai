## 1. 카메라 설치 조건
### 1-1. 설치 높이
- [ ] 2m 미만  - [ ] 2~3m  - [ ] 3~4m  - [ ] 4m 이상
> 왜 필요? 높이에 따라 사람 크기가 달라지므로 검출 박스의 최소·최대 크기 필터 기준이 된다.

### 1-2. 촬영 각도
- [ ] 수직 위에서 아래(탑뷰)  - [ ] 비스듬히(30~60도)  - [ ] 거의 정면
> 왜 필요? 각도에 따라 원근 보정(perspective transform) 적용 여부와 사람끼리 가림 정도가 결정된다.

### 1-3. 화면에 보이는 개찰구 수
- [ ] 1~2개  - [ ] 3~4개  - [ ] 5개 이상
> 왜 필요? 개찰구별 관심 영역(ROI)과 통과선(line)을 몇 개로 나눌지 정하는 기준이 된다.

### 1-4. 화면에 개찰구 외 영역(벽, 통로, 상점 등)이 차지하는 비율
- [ ] 거의 없음  - [ ] 절반 이하  - [ ] 절반 이상
> 왜 필요? 불필요한 영역을 마스킹해야 오검출과 연산량을 줄일 수 있다.

### 1-5. 카메라 흔들림
- [ ] 없음  - [ ] 열차 진입 시 약간  - [ ] 자주 흔들림
> 왜 필요? 흔들림이 있으면 영상 안정화(stabilization)를 넣거나 통과선 위치에 여유를 둬야 한다.

## 2. 조명 환경
### 2-1. 주 광원
- [ ] 형광등  - [ ] LED  - [ ] 자연광 혼합  - [ ] 혼합(구역마다 다름)
> 왜 필요? 형광등은 깜빡임(flicker)이 생길 수 있어 프레임 간 밝기 보정 필터가 필요하다.

### 2-2. 밝기 수준 (눈으로 판단)
- [ ] 밝음  - [ ] 보통  - [ ] 어두움  - [ ] 구역별 차이 큼
> 왜 필요? 어둡거나 밝기 차가 크면 히스토그램 평활화(CLAHE) 같은 명암 보정 강도를 정해야 한다.

### 2-3. 역광 (출입구·창문에서 빛이 들어옴)
- [ ] 없음  - [ ] 특정 시간대만  - [ ] 항상 있음
> 왜 필요? 역광이 있으면 사람이 검은 실루엣으로 찍혀 노출 보정이나 해당 영역 별도 처리가 필요하다.

### 2-4. 그림자
- [ ] 거의 없음  - [ ] 옅게 생김  - [ ] 진하고 길게 생김
> 왜 필요? 진한 그림자는 사람으로 오인될 수 있어 그림자 제거 또는 검출 신뢰도 임계값을 높여야 한다.

## 3. 배경 및 간섭 요소
### 3-1. 바닥 재질
- [ ] 무광(반사 없음)  - [ ] 약간 반사  - [ ] 심한 반사(대리석·광택)
> 왜 필요? 바닥에 비친 사람이 중복 검출될 수 있어 반사 영역 마스킹이 필요하다.

### 3-2. 화면 안의 유리·거울·스테인리스 면
- [ ] 없음  - [ ] 있음 (위치: ________)
> 왜 필요? 반사된 사람 형상을 제외하도록 해당 위치를 마스크로 지정해야 한다.

### 3-3. 화면 안의 디지털 광고판·모니터
- [ ] 없음  - [ ] 있음(정지 화면)  - [ ] 있음(영상 재생)
> 왜 필요? 광고 속 사람 이미지나 움직임이 오검출을 일으키므로 고정 마스크 처리 대상이다.

### 3-4. 화면 안에서 계속 움직이는 배경
- [ ] 없음  - [ ] 에스컬레이터  - [ ] 문(자동문)  - [ ] 기타: ________
> 왜 필요? 배경 움직임은 추적 오류의 원인이므로 해당 영역을 제외하거나 움직임 필터를 적용해야 한다.

## 4. 개찰구 구조
### 4-1. 개찰구 유형
- [ ] 플랩형(문이 열림)  - [ ] 턴스타일(회전 막대)  - [ ] 광폭형(휠체어용)  - [ ] 혼합
> 왜 필요? 유형마다 사람이 지나가는 위치와 속도가 달라 통과선 위치와 추적 파라미터가 달라진다.

### 4-2. 통과 방향
- [ ] 입장 전용  - [ ] 출구 전용  - [ ] 양방향  - [ ] 시간대별 전환
> 왜 필요? 방향 판별 로직이 필요한지, 입·퇴장을 따로 셀지 결정하는 기준이 된다.

### 4-3. 개찰구 앞 대기 공간
- [ ] 넓음  - [ ] 보통  - [ ] 좁음(바로 계단·통로)
> 왜 필요? 대기 공간이 좁으면 사람이 겹쳐 서 있어 가림(occlusion) 대응 설정을 강화해야 한다.

## 5. 승객 흐름 패턴
### 5-1. 체감 혼잡도
- [ ] 여유  - [ ] 보통  - [ ] 혼잡  - [ ] 매우 혼잡
> 왜 필요? 밀집도에 따라 겹친 박스를 제거하는 NMS 임계값과 추적 매칭 기준을 조정해야 한다.

### 5-2. 통과 모양
- [ ] 한 명씩 일렬  - [ ] 2~3명씩 붙어서  - [ ] 덩어리로 몰림
> 왜 필요? 붙어서 지나가면 한 명으로 합쳐 세질 수 있어 분리 검출 기준을 정하는 근거가 된다.

### 5-3. 개찰구 앞에서 멈추는 사람 (카드 찾기, 오류 등)
- [ ] 거의 없음  - [ ] 가끔  - [ ] 자주
> 왜 필요? 멈췄다 다시 움직이는 사람을 중복으로 세지 않도록 동일 인물 판정 시간(쿨다운)을 정해야 한다.

### 5-4. 비정상 이동 (역방향, 되돌아감, 꼬리물기)
- [ ] 거의 없음  - [ ] 가끔  - [ ] 자주
> 왜 필요? 선을 넘었다 돌아가는 경우를 걸러내는 방향·궤적 필터의 필요성을 판단한다.
